# 关于

Workshop Template 是面向 SSTIA workshop 主讲人的起始模板。它打包了一套完整的 MkDocs + Material for MkDocs 配置——双语构建、GitHub Pages 部署、讨论区与媒体支持——让讲义在几分钟内变成一个网站。

## 作者

模板由 Cedric Haskell 维护。问题与建议可以在 [GitHub issues](https://github.com/CedricHaskell/WorkshopTemplate/issues) 中提出。

## 许可证

模板以 MIT License 发布，见 [LICENSE](https://github.com/CedricHaskell/WorkshopTemplate/blob/main/LICENSE)。

## 贡献

欢迎贡献。流程见 [CONTRIBUTING.md](https://github.com/CedricHaskell/WorkshopTemplate/blob/main/CONTRIBUTING.md)，简而言之：先开 issue 讨论修改内容，再提交 pull request。每个 pull request 都会运行健康检查（`mkdocs build --strict`）。
