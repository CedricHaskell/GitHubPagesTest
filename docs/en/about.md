# About

Workshop Template is a starter kit for SSTIA workshop hosts. It packages a complete MkDocs + Material for MkDocs setup — bilingual build, GitHub Pages deployment, discussion board, and media support — so that a worksheet becomes a website within minutes.

## Author

The template is maintained by Cedric Haskell. Questions and suggestions can be raised as [GitHub issues](https://github.com/CedricHaskell/WorkshopTemplate/issues).

## License

The template is released under the MIT License; see [LICENSE](https://github.com/CedricHaskell/WorkshopTemplate/blob/main/LICENSE).

## Contributing

Contributions are welcome. The [CONTRIBUTING.md](https://github.com/CedricHaskell/WorkshopTemplate/blob/main/CONTRIBUTING.md) file describes the process; in short: open an issue to discuss the change, then submit a pull request. Every pull request runs the health check workflow (`mkdocs build --strict`).
